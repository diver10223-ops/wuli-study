🧭 矢量处理 · 逆向匀加速 根治粗心

📐 标准矢量流程

  • ① 规定正方向（通常取初速度方向）
  • ② 确定 v₀, v, a, x 的 符号
  • ③ 代入公式（如 v = v₀ + at）
  • ④ 结果 带方向解释（“与正方向相同/相反”）

🔄 逆向匀加速（秒杀技巧）

  • 适用：匀减速（刹车、上抛）
  • 核心：将末速度为零的过程 反向 看成初速为零的匀加速
  • 👉 例：刹车距离 x = v₀²/(2a) → 逆向：x = ½a t²
  • 避开了负号，计算更直观
📌 实战示例：汽车以 20 m/s 刹车，加速度大小 5 m/s²，求刹车位移。
正向：0² − 20² = 2·(−5)·x → x = 40 m。
逆向：看成初速 0，加速度 5 m/s² 的匀加速，x = ½·5·(20/5)² = 40 m。 ✓ 更快
📊 图像升级 · 多过程模型 压轴必备

🔹 非常规图像

  • a−t 图：面积 = Δv
  • x/t − t 图：斜率 = a/2，截距 = v₀
  • v²−x 图：斜率 = 2a

🔸 多过程模型

  • 先加后减（电梯）：v−t 图折线，位移 = 面积
  • 竖直上抛全程：a = −g，对称性（等时等速）
  • 折返运动：先减速至零，再反向加速
🔥 高频考点：竖直上抛物体，上升时间 t₁ = v₀/g，下落时间 t₂ = t₁，全程位移 0（回到原点），路程 2·(v₀²/2g)。
🚦 追及相遇 · 临界条件 灵魂
  • 核心临界：速度相等时，距离有最值（最大或最小）
  • ① 若追者速度 < 被追者，距离 增大
  • ② 若追者速度 > 被追者，距离 减小
  • ③ 恰好不相撞 ⇔ 速度相等时，位移差 ≤ 初始距离
📐 解题模板
1. 设时间 t，写出 x₁, x₂ 表达式
2. 令 Δx = x₁ − x₂ (或 x₂ − x₁)
3. 速度相等：v₁ = v₂ 求临界 t
4. 判断 Δx 与初始距离关系
🔬 实验创新 · 光电门 & 误差 新高考

💡 光电门测速

  • 瞬时速度 v = d / Δt （d 为遮光片宽度）
  • 加速度：a = (v₂² − v₁²) / 2x
  • 注意：d 越小，测量越接近瞬时速度

📉 误差分析

  • 系统误差：摩擦阻力、纸带振动的滞后
  • 偶然误差：读数、计数点选取
  • 逐差法 可有效减小偶然误差
🔥 常考变形：若只给 4 段数据 (x₁~x₄)，a = (x₃+x₄ − x₁−x₂) / (2T)²
📝 高考母题 · 规范表达 步骤分
【2023 全国甲卷·改编】

汽车以 72 km/h 行驶，刹车加速度大小 4 m/s²，求 5 s 内位移。

✅ 规范解答
① 规定初速度方向为正，v₀=20 m/s，a=−4 m/s²
② 刹车时间 t停 = v₀/|a| = 5 s
③ 因 t给=5 s = t停，车刚好停下
④ x = v₀t + ½at² = 20×5 + ½·(−4)·25 = 50 m
【2022 广东卷·改编】

一小球从离地 45 m 高处自由下落，g=10 m/s²，求落地前最后 1 s 的位移。

✅ 规范解答
① 落地总时间 t = √(2h/g) = 3 s
② 前 2 s 位移 x₂ = ½·10·4 = 20 m
③ 最后 1 s 位移 = 45 − 20 = 25 m
💡 也可用比例：1:3:5 → 第3s位移 = 5×5 = 25 m
📌 规范表达黄金法则：① 写原始公式（如 v = v₀+at） → ② 代入数据（带单位） → ③ 计算结果（注明方向）
⚡ 比例法速算（v₀=0 匀加速） 秒杀
等时位移比 (1s, 2s, 3s…)
x₁ : x₂ : x₃ : … = 1 : 4 : 9 : …
连续相等时间位移比
Δx₁ : Δx₂ : Δx₃ : … = 1 : 3 : 5 : …
等位移时间比 (x, 2x, 3x…)
t₁ : t₂ : t₃ : … = 1 : √2 : √3 : …
连续等位移时间比
Δt₁ : Δt₂ : Δt₃ : … = 1 : (√2−1) : (√3−√2) : …
🔥 注意：以上比例 仅适用于 v₀=0 的匀加速，选择题直接秒杀！
