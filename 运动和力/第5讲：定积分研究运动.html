📖 第5讲：定积分研究运动

整理日期：2026.07.16
a(t) —积分→ v(t) = ∫a·dt —积分→ x(t) = ∫v·dt
⭐ 积分求的是 累积量 — 对应物理中的“速度变化量”和“位移”
📐 定积分的物理含义
  • ∫a·dt = 速度变化量 Δv（a-t 图面积）
  • ∫v·dt = 位移 Δx（v-t 图面积）
  • 几何意义：积分 = 曲线与坐标轴围成的 面积
  • ⚠️ 定积分给的是“变化量”，不是“末状态值”
💡 常用积分
∫tⁿdt = tⁿ⁺¹/(n+1) + C
∫sin t dt = −cos t + C
∫cos t dt = sin t + C
📌 定积分在运动学中的应用
  • ① 已知 a(t) → 求 v(t) 和 x(t)
  • ② 变加速运动：a = f(t)，只能用积分求 v 和 x
  • ③ 平均速度：\bar{v} = (1/Δt)·∫v·dt
🔥 典型模型
a = kt（加速度随时间线性变化）
a = kv（加速度与速度相关，需分离变量再积分）
📝 常见题型
题型1 已知 a-t 图，求 v-t 图或 x-t 图（面积法）
题型2 已知 a(t) 表达式，积分求 v(t) 和 x(t)
题型3 变加速运动中，求某段时间内的位移
题型4 用定积分求平均速度或平均加速度
🧩 易混淆点
概念含义与导数的关系易错
∫a·dt速度变化量 Δv导数的逆运算忘记加初速度 v₀
∫v·dt位移 Δx导数的逆运算忘记加初始位置 x₀
❌ 常错题（易掉坑）
错题1 已知 a=2t，v₀=0，求 t=3s 时的速度。
错误做法：v = a·t = 2×3×3 = 18 m/s ❌
正确做法：v = ∫a·dt = ∫2t·dt = t²，t=3时 v=9 m/s ✅
错题2 v-t 图中面积求的是路程还是位移？
错误：一律当成路程 ❌
正确：轴上方为正位移，轴下方为负位移，面积代数和=位移；取绝对值之和=路程 ✅
错题3 定积分 ∫v·dt 从 t₁ 到 t₂ 得到的是什么？
错误：得到末位置 x(t₂) ❌
正确：得到 位移变化量 x(t₂)−x(t₁) ✅
🔗 交叉题型（与其它章节结合）
① 导数+积分混合：已知 x(t) 求 v(t)，再积分求总路程（求导→积分）
② 微元法+定积分：非匀变速中，先取微元列式，再积分求和
③ 第2讲+第5讲：v-t 图面积求位移（图像法本质就是定积分）
