# M2匀变速直线运动三轨知识矩阵与考卷规格

## 三轨边界

- A轨：正方向、恒加速度关系、图像、刹车、自由落体、分段和实验；正式卷80%，分项与门槛同时通过。
- B轨：追及相遇、初始距离、反应制动、最近距离、图像重构、多解筛选和实验评价；正式卷75%，至少一道新情境独立完成。
- C轨：变化率、导数、积分、变加速、分段函数、数值近似和参数临界；正式卷70%，工具条件门槛和独立证据同时通过。C轨不计入A轨普通高考出关。

## 六阶段

每轨均有诊断、学习、模型、即时检测、正式卷和间隔复测。A/B/C使用`physics-mechanics-m2-{track}-{stage}-v1`独立键。

## 内容节点

| 轨道 | 核心节点 | 出关证据 |
|---|---|---|
| A | 速度加速度、符号、基本关系、图像、刹车、自由落体、分段、实验 | A正式卷+新题复测 |
| B | 位置函数、相对位移、追及、临界、图像重构、多解、实验评价 | B正式卷+迁移复测 |
| C | 极限直观、导数、积分、变加速、数值法、参数和工具边界 | C正式卷+工具复测 |

## S0—S11映射

诊断对应S0；学习覆盖S1—S3；模型覆盖S4—S6；即时检测驱动S7；B/C拓展覆盖S8；正式卷对应S9；复测对应S10；M2与牛顿定律、能量和电磁直线运动的连接对应S11。
