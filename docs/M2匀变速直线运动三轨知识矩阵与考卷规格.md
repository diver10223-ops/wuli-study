# M2 匀变速直线运动三轨知识矩阵与考卷规格

## 内容依据与边界

M2 以根目录《物理笔记.md》知识点 8—11 为边界：匀变速直线运动、自由落体、竖直抛体和一般变速直线运动。知识点 12“不同参考系下运动描述的转换”属于 M1 已涉及的边界，本模块只为多对象题统一地面坐标与计时，不建设参考系变换、伽利略变换或非惯性系内容。

三轨不能相互补偿：A 是北京高中教材核心；B 在 A 的运动学模型上进行综合迁移；C 是连接具体运动学问题的强基数学工具，不替代 A 轨出关证据。

## 知识矩阵

| 轨道 | 节点 | 可审查内容 | 正式卷任务 |
|---|---|---|---|
| A | M2-K01—K08 | 速度与加速度、正方向、三组基本关系、v-t 图像、刹车有效时间、自由落体、竖直上抛、逐差实验 | K01—K08 |
| B | M2-BK01—BK08 | 位置函数与相遇、初距、反应和制动分段、最近距离临界、多对象图像、多解筛选、实验数据、误差评价 | BK01—BK08 |
| C | M2-CK01—CK08 | 变化率极限、导数、积分有向累积、由 a(t) 恢复运动、由 v(t) 求位移与路程、数值积分、参数临界、工具适用边界 | CK01—CK08 |

所有学习项、模型和客观题均直接标注 `node`；正式卷每题同时标注 `task`，且三轨正式卷分别覆盖本轨全部八个节点。复测继续映射原矩阵节点，但换用不同物理情境，不另造“复测节点”。

## 六阶段和证据规格

每轨复用参数化页面及 `assets/diagnostic.js`、`learning.js`、`assessment.js`、`written-assessment.js`、`progress.js`、`evidence.js` 与 `storage.js`，保留诊断、知识学习、模型训练、即时检测、正式卷和间隔复测。证据键为 `physics-mechanics-m2-{track}-{stage}-v1`，A/B/C 独立存储。

| 轨道 | 正式卷门槛 | 关键约束 |
|---|---|---|
| A | 总分 ≥80% | 分项、关键门槛均通过 |
| B | 总分 ≥75% | 分项、关键门槛均通过，至少一道新情境标为独立完成 |
| C | 总分 ≥70% | 导数、积分和工具边界门槛通过，存在独立作答证据 |

复测题不得与即时检测或正式卷复用题干；B/C 的通过状态不能写入或补偿 A 轨证据。

## 物理自查口径

逐题检查正方向、速度和加速度符号、单位、积分的有向性、刹车停止后的有效时间、分段根所在区间、竖直上抛双时刻、答案索引及实验误差措辞。自动审计只能验证结构与显式规则，不能代替教师审校。
