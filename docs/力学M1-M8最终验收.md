# 力学M1—M8最终验收

## 交付结论

- M1—M8均有独立模块入口、模块进度、A/B/C三轨和每轨六阶段；
- 共8个模块、24条轨道、144个阶段配置/页面纳入统一证据协议；
- 每模块有知识矩阵与质量审计，三轨正式卷门槛分别为80%、75%、70%；
- 总进度、模块进度和导出均只读取本机证据，B/C不能补偿A轨；
- 旧HTML/PDF作为来源保留，不作为互动课程完成证据。

## 自动验收

`python3 tests/audit_mechanics.py`验证全部页面、配置、路由、存储键、JavaScript语法、进度和规格。`python3 tests/audit_electric.py`作为跨领域回归。

## 发布后质量工作

结构完成不等于外部教学验证完成。教师逐题审校、真实手机试学、学校作业/考试迁移验证和北京范围权威核验继续作为发布治理工作记录，不伪装成自动测试通过。
