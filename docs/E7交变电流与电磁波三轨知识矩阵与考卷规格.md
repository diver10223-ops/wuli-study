# E7交变电流与电磁波三轨知识矩阵与考卷规格

## 三轨边界
- A轨：正弦量、有效值、理想变压器、输电、电磁振荡与波谱。
- B轨：非正弦、多副线圈、动态负载、输电网络与信息传输。
- C轨：相量/RLC边界、谐振、场观点、波导、编码噪声与频谱思想。
