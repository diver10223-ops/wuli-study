# M1 运动的描述三轨知识矩阵、考卷规格与质量审计

## 课程边界与三轨差异

M1只建设“如何描述运动”，不提前使用M2的匀变速运动公式。三轨不是同题换标题：A轨形成高中运动学基本语言，B轨处理参考系迁移、关联约束与实验评价，C轨用二维矢量、参数方程和瞬时变化率建立强基先修工具。B/C轨均以前一轨正式卷通过为准入条件，不能补偿A轨。

| 轨道 | 定位 | 学习产出 | 正式卷门槛 |
|---|---|---|---|
| A 基础核心 | 教材概念与基础实验 | 能区分质点/实体、时刻/时间、位移/路程、平均/瞬时量，并用速度与加速度方向判断速率变化 | 80%，关键概念门槛不得猜对 |
| B 迁移拔高 | 多对象、约束与实验设计 | 能转换平移参考系、由绳长约束求关联速度、解读多对象图像并评价数字化测量误差 | 75%，关键门槛通过且含独立作答证据 |
| C 强基先修 | 二维与变化率工具 | 能作矢量合成、求参数运动瞬时量、区分位移与微元路程，并声明非惯性系边界 | 70%，关键门槛通过且含独立作答证据 |

## 六阶段内容规格

1. **诊断**：每轨6题定位到6个知识节点，关键边界题启用门槛；B、C依次读取前一轨正式卷证据。
2. **知识学习**：每轨6张真实内容卡，逐项给出定义或规律、适用条件、具体误区、最小例证和可勾选产出。
3. **模型训练**：每轨6个不同情境模型，强调“建系—关系—计算—边界检验”，不复述学习卡。
4. **即时检测**：每轨6题覆盖全部节点，通过后才允许进入正式卷。
5. **正式卷**：每轨8题，全部题目以`node`和`task`字段映射上表；后两题作为同轨迁移题，B/C要求至少一道题标记为独立完成。
6. **间隔复测**：正式卷通过14天后使用3道节点抽样题复测，满分且关键门槛通过才形成稳定证据。

## 自动验收、审校与验证口径

- `python3 tests/audit_mechanics.py --module M1`检查18份配置、共享页面路由、存储键和规格文件。
- `node tests/test_mechanics_catalog.js --module M1`额外拒绝遗留通用模板措辞，检查所有内容均有节点映射、三轨检测题无重复题干，并确认三份正式卷覆盖各自6个矩阵节点。
- 自动审计只能证明技术结构和映射一致，不能替代教师对概念边界、数值答案、表述和难度的物理审校，也不能替代学生真实作答验证。
