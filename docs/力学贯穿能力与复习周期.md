# 力学贯穿能力与R1—R6复习周期

## 贯穿能力

M1—M8每一轨都以“对象—过程—条件—规律—方程—检验”组织任务，并持续检查方向、单位、有效区间和物理意义。实验任务统一覆盖目标、器材、变量、数据、图像、误差、改进和证据表达。

## 数学工具分轨

- A轨使用比例、函数、方程、几何、三角和图像；
- B轨使用参数、分段、临界、相对量和微元思想；
- C轨使用极限、导数、积分、微分方程与数值方法，且不得补偿A轨。

## R1—R6

R1预习建立概念和章节地图；R2随堂巩固模型、变式与实验；R3期中期末混合出关；R4高三一轮重建知识树；R5专题二轮强化跨章迁移；R6考前回归错因、真题与表达。每轮继承已有证据，但正式卷和复测仍需按目标轨独立通过。

## 跨章连接

运动学连接受力和牛顿定律；曲线与圆周连接能量；万有引力连接圆周；动量连接能量与振动；全力学与电磁场中的带电粒子、安培力运动和电磁感应能量问题建立双向修复路由。
