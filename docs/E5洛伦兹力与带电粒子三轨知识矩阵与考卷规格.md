# E5洛伦兹力与带电粒子三轨知识矩阵与考卷规格

## 三轨边界

- A轨：北京普通高考主线，强调方向、圆周、几何、时间、速度选择和比荷。
- B轨：多边界、临界、多区域、复合场和陌生装置迁移。
- C轨：强基/大学先修的螺旋、聚焦、回旋近似、分辨率、数值思想和探究。

## 考卷规则

A卷≥80，B卷≥75，C卷≥70；所有轨道分项≥60%，关键门槛不得错答或猜对。每次正式卷保存薄弱任务和1/3/7天复测日期。C轨不替代普通高考A/B轨。
