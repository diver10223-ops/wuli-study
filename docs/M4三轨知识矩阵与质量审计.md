# M4 牛顿运动定律三轨知识矩阵与质量审计

## 内容边界与三轨认知差异

M4只处理牛顿定律及其动力学应用。受力分析作为列动力学方程的步骤复用M3能力；不把抛体、圆周运动、功和能量、动量守恒设为门槛。A轨处理单对象和规范方程，B轨处理多对象、约束、临界与状态切换，C轨处理参数、非惯性系、变质量边界、微分方程与数值近似。三轨不是标题、数字或难度标签的替换。

## 六阶段题量与证据映射

每轨均为诊断6题、学习6项、模型6项、即时检测6题、正式卷6题、间隔复测6题。每一阶段按K01—K06逐项映射上述六个节点，因此正式卷与复测均有每节点一条证据；这只称为“节点覆盖”，不声称单题构成节点内的层次覆盖。B/C诊断分别以前一轨正式卷为先修证据，学习与模型读取本轨诊断，正式卷读取本轨即时检测，复测读取本轨正式卷。

## 正式卷门槛与规格

- A轨：基础概念、单对象动力学、两类动力学问题、超重失重与实验/图像证据，门槛80%。
- B轨：多对象、整体与隔离、连接约束、临界分离、临界滑动、传送带/板块和实验迁移，门槛75%。
- C轨：非惯性系、参数范围、阻力模型、变质量边界、微分方程、数值近似和模型评价，门槛70%。

## 模板清除、重复与答案分布

原有63道测评题（每轨诊断6、检测6、正式卷6、复测3）全部是通用模板，其中答案均在索引0；36条学习/模型内容也为通用占位。本轮返工全部36条学习/模型内容和63道原题，并把复测补至每轨6题，形成72道真实测评题。各轨各测评阶段答案索引均按`0/1/2`各2题分布，最大连续相同位置为1。题干逐项使用不同装置、物理量或判断任务；归一化扫描无同题干、跨轨同题干或只换数字/对象/单位的未处理组。

## 编写者逐题物理自查

编写者对72道测评题逐题检查研究对象、地面或随动参考系、真实力、正方向、分量方程、代入、候选解、约束、答案索引、唯一答案与两个错误选项来源。每题配置中的`review`保存这条可审查链；错误项分别对应漏力、把单力当合力、速度方向代替加速度、单位混淆、保留负接触力、越过静摩擦范围、遗漏步长或误把惯性力当真实力等具体路径。复算中修正了原配置的63个答案集中问题；原题不含可复算物理过程，故不把模板替换虚报成“修正物理错误”。

## 发现与修正

发现B、C节点名称与指定矩阵错位、三轨复测只覆盖前三节点、所有题答案固定、阶段间题干完全复用、学习与模型五字段职责相同。现已按矩阵重命名和重写，补齐复测节点，分散答案，为学习写概念与算例，为模型写对象—参考系—真实力—方程—候选解—约束—结论链。没有增加页面或共享引擎，也没有扩展到M3、M5或能量/动量门槛。
