# M4 牛顿运动定律三轨知识矩阵与质量审计

## 三轨内容

- A轨（基础核心）：牛顿第一定律与惯性、牛顿第二定律、单位制、已知力求运动、已知运动求力、超重失重与实验；正式卷门槛80%。

- B轨（迁移拔高）：连接体、临界分离、临界滑动、传送带、板块模型、多过程动力学；正式卷门槛75%。

- C轨（强基先修）：非惯性参考系、惯性力、变质量初步、阻力模型、微分方程形式、数值动力学；正式卷门槛70%。

## 统一流程

每轨均包含诊断、学习、模型、即时检测、正式卷和间隔复测；正式卷和复测都通过才表示稳定。B/C不能补偿A轨。
