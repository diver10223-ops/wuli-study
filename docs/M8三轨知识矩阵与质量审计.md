# M8 动量、振动与机械波三轨知识矩阵与质量审计

## 三轨内容

- A轨（基础核心）：冲量与动量定理、动量守恒、碰撞与反冲、简谐运动与单摆、机械波图像波速、干涉衍射多普勒；正式卷门槛80%。

- B轨（迁移拔高）：多体碰撞、动量能量联合、碰撞后振动、振动参数变化、波形与振动图转换、波的多解与实验；正式卷门槛75%。

- C轨（强基先修）：质心与质心系、二维碰撞、振动微分方程、阻尼驱动与相位、驻波与相位差、波动方程初步；正式卷门槛70%。

## 统一流程

每轨均包含诊断、学习、模型、即时检测、正式卷和间隔复测；正式卷和复测都通过才表示稳定。B/C不能补偿A轨。
