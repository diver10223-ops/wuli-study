# E4磁场与安培力三轨全流程质量审计

## 审计结论

E4 已形成 A基础、B拓展、C强基三条独立学习路线。每轨均具备诊断、学习、检测和正式考卷；C卷书面推导与探究题必须由家长或教师审核，不以选择题分数代替论证能力。

## 路由与门槛

| 轨道 | 入口 | 学习证据 | 出关证据 |
|---|---|---|---|
| A | 前置诊断 | 13个知识节点与6个模型任务 | A卷≥80且分区、关键门槛通过 |
| B | A卷通过或B准入诊断 | 8项陌生情境迁移任务 | B卷≥75，空间叠加、能量与独立作答通过 |
| C | B卷通过、工具诊断与强基目标 | 8项推导、测量与探究任务 | C卷≥70，人工审核、独立推导、探究结构通过 |

## 数据边界

- 所有记录仅保存在当前浏览器 `localStorage`，不上传姓名、原卷或答案。
- 总进度页可导出 JSON 备份；换设备或清理浏览器数据前必须导出。
- A/B/C 是内容深度，诊断—学习—检测—考卷是执行阶段，两者不得混为一维目录。
- C轨不是普通高考默认任务，C轨通过也不能替代A/B轨间隔复测和校内考试验证。
