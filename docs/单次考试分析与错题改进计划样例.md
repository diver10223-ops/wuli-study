# 单次考试分析与错题改进计划样例

> 样例来源：用户上传的一次高一物理线下诊断考试。
> 资料范围：用户说明共4页试题、3页答题资料（1页问答题、2页解答题），并提供了客观题得分表和答题卡图像。
> 隐私规则：报告不记录学生姓名、准考证号、学校账号、二维码等个人标识；原图进入系统前应自动遮盖这些信息。
> 分析限制：当前没有官方答案、完整教师批注和考试用时记录。能从卷面确认的结论标“已确认”，需要答案或教师核验的标“待核验”，不根据模糊图像猜正确答案。

## 2. 总体判断

### 2.1 已经表现出的能力

1. **有完整作答和规范列式意识。** 第15题全对，第17题8/9，说明在模型识别清楚时能够连续列式并完成多问计算；
2. **基础电路计算并非完全薄弱。** 第16题前两问得分，能够由端电压和外电路关系求总电流、电源效率；
3. **实验基本操作有一定基础。** 第13、14题各只丢2—3分，表明多用电表步骤、读数、伏安法基本结构和图像读取已有基础；
4. **书写中能保留公式。** 多数主观题不是只写数字，为后续纠错提供了过程证据；
5. **带电粒子基础模型可以得满分。** 第15题8/8，说明直线通过磁场的几何和洛伦兹力基本关系至少在该题情境中能够使用。

### 2.2 最需要改进的结构性问题

1. **选择题失分面过宽。** 12题只有第2、6、9题满分，其他9题均有失分，说明问题不只是“某一章不会”，还包括多选题判定、概念边界和陌生装置阅读；
2. **综合题出现整题放弃。** 第18题9分空白，第19题虽有尝试但12分全失，至少21分没有形成有效得分步骤；
3. **支路电流与总电流混淆。** 第16题第3问把干路总电流直接当作电动机电流，导致机械功率错误，这是研究对象/电路节点错误，不应归为普通计算粗心；
4. **复杂电磁题缺少“分阶段、分装置”建模。** 第19题将速度选择、磁场圆周运动、几何半径和比荷推导混在一起，公式出现但缺乏条件链；
5. **实验图像斜率和仪表原理仍不稳定。** 第13、14题的局部失分指向二极管极性判断、图像斜率/截距或结果表达，需要结合官方答案核验；
6. **实际考试证据低于部分单题能力。** 能完成第15、17题却在大量选择和第18、19题失分，可能同时存在知识覆盖、时间分配和难题策略问题；由于没有每题用时，本项暂不能下最终结论。

#### 第16题第3问的已确认错误

学生先算出通过电源和串联电阻的总电流`I=3 A`，但电动机与`R₂=6 Ω`并联，电动机两端电压为`6 V`。因此还应先计算`R₂`支路电流，再由节点关系得到电动机电流。卷面直接使用`3 A`计算电动机机械功率，研究对象选错。修复重点不是重做乘法，而是每遇并联电路先标注“干路电流/各支路电流”。

#### 第18题的空白不能直接标为“不会”

需要补问：

1. 是否读懂装置；
2. 是否知道磁场只改变方向、电场改变动能；
3. 是否知道半圆周期与速度无关；
4. 是否因为前题耗时而没有开始；
5. 是否会第1问但误以为必须整题做完才落笔。

诊断后再区分“知识空白、模型空白、计算畏难、时间不足或答题策略”。

#### 第19题不宜直接讲完整答案

应先拆成四个较小能力：

1. 平行板电场与磁场共存时写出不偏转条件；
2. 只保留磁场后由轨迹几何确定半径；
3. 联立`qvB=mv²/r`推导比荷；
4. 圆柱/轴向磁场情境下重新确定受力、轨道和临界条件。

只有前一级独立通过才进入下一级，避免看懂整题解析后仍不会重新建模。

## 5. 错题改进计划

### 5.1 改进目标

第一阶段不以马上做到全部压轴题为目标，而以“把已有能力转化为稳定基础分，并让综合题开始有步骤分”为目标。

建议下一次同范围考试的过程目标：

1. 选择题不再出现连续大面积0分，先减少明显概念和装置判断错误；
2. 实验题保持基本操作得分，补回图像斜率/仪表原理的3—5分；
3. 第16类电路计算确保支路电流不混；
4. 第17类规范表达补齐方向、单位和有效对象；
5. 第18、19类综合题即使不能做完，也要完成已确认的受力式、能量关系、周期或几何条件，避免整题空白；
6. 记录每道大题开始时间，为时间不足与知识不会提供证据。

### 5.2 四个改进包

#### IMP-01 动态电路与电流对象（最高优先级）

**关联题：**第5、7、11、16.3。
**核心错因：**等效电路、干路/支路电流、仪表内阻与功率对象。
**当天修复：**

1. 在第16题电路图上分别标出总电流、`R₂`电流和电动机电流；
2. 不看原解析，重新完成第16.3；
3. 做2道并联支路功率基础题；
4. 做1道电流表改装题和1道滑动变阻器动态判断题。

**完成标准：**连续两道新题中都先写节点关系，电动机功率使用正确支路电流，且能说明错误原解为什么错。
**复测：**1天、3天、7天；下一次校内小测作为线下验证。

#### IMP-02 磁场方向、安培力与装置判断（高优先级）

**关联题：**第3、4、8、10。
**核心错因：**方向规则、场叠加、受力—运动—能量链条。
**修复动作：**

1. 每题必须画电流/速度、磁场和受力三向关系；
2. 分别训练“只判方向”“只判大小”“判断能量变化”，不在一开始混合；
3. 对多选题每个选项写一句成立条件；
4. 完成一道平行导线、一道人体/导轨安培力、一道霍尔效应变式。

**完成标准：**不是只选对答案，而是四个选项均能给出理由；连续两次方向题无左右手规则错误。
**复测：**1天和3天；7天加入混合装置题。

#### IMP-03 实验原理与图像（中高优先级）

**关联题：**第13.2.2、第14.2.2、第14.4。
**核心错因：**仪表内部极性、斜率/截距物理意义、实验图像评价。
**修复动作：**

1. 画出欧姆挡内部电源与红黑表笔方向，重新判断二极管极性；
2. 在第14题图像上选两点，完整写`斜率=纵轴变化/横轴变化`及单位；
3. 区分“读截距、求斜率、看曲线形状”三个任务；
4. 对第14.4每个候选图像分别说明正确或错误原因。

**完成标准：**换一张图仍能从坐标轴、斜率和截距推出物理量，不能只背本题数字。
**复测：**3天、7天。

#### IMP-04 电磁综合题启动与分步得分（分层长期计划）

**关联题：**第18、19。
**核心错因：**复杂装置没有拆阶段，公式未与条件和几何对应，可能叠加时间策略问题。
**修复顺序：**

1. 回旋加速器：只练“磁场半圆运动”和“电场缝隙加速”两个阶段；
2. 单独推导半圆时间、最大速度/动能与出口半径的关系；
3. 速度选择器：先完成不偏转条件；
4. 单独做磁场圆轨迹的几何半径；
5. 再联立推导比荷；
6. 最后才回到第18、19整题。

**考场策略：**读完题后先写每个阶段确定成立的原始关系；若3分钟没有推进，暂时跳到下一问或下一题，保留已写的步骤分。
**完成标准：**一道同结构新题中，即使不能算到底，也能独立写出阶段划分、核心方程和至少一个可评分结论。
**复测：**3天基础分解题、7天半综合、14天整题；下一次阶段考试线下验证。

### 5.3 低成本补分项

1. 第1、4题属于部分得分，应优先核对漏选还是错选；
2. 第17题只少1分，拿到评分标准后补齐方向、单位或表达；
3. 第14题局部错误不应整章重学，精确修复斜率和图像判断；
4. 第15题虽满分，7天后用不同几何入口复测，防止只会原题。

单日修复不建议超过45分钟；正常校内学习仍是主线。若学校近期正在学习新章，两周计划应缩减为每天20—30分钟，优先IMP-01、IMP-02和低成本补分项。

## 7. 下一次考试的验证指标

不能只比较总分，还应比较：

| 指标 | 本次基线 | 下次观察目标 |
|---|---:|---|
| 客观题得分 | 13/36 | 明显减少0分题；每个多选保留选项理由 |
| 实验题得分 | 13/18 | 图像斜率和仪表原理不再重复丢分 |
| 第16类支路错误 | 已发生 | 不再把总电流当支路电流 |
| 大题整题空白 | 第18空白；第19后半空白 | 至少写出阶段和核心关系，争取步骤分 |
| 已修复错误复发 | 尚无后测 | 分别记录“未复发/再次复发” |
| 时间记录 | 缺失 | 记录开始解第15—19题的时刻 |
| 提示依赖 | 线下考试不适用 | 考后复测记录最高提示级别 |

总分目标应在取得官方答案、考试难度和同类表现后再设定。当前更合理的是先用上述过程指标判断改进是否真实发生。

## 9. 本样例对网站设计的验证

这次真实试卷说明，未来上传系统至少必须支持：

1. 一次考试多批图片，并标注题目页、答题页、批改页和成绩页；
2. 自动遮盖姓名、考号、二维码等未成年人隐私；
3. 同一大题按小问保存得分，不能只保存大题总分；
4. 区分多选题的漏选、错选和含错误选项；
5. 保存学生原始过程，而不是只保存正确答案；
6. 对OCR不确定内容请求人工确认；
7. 将一个错误关联到多个知识/能力节点，但必须指定主错因；
8. 区分网站复测通过和后续线下考试验证通过；
9. 支持“不会、来不及、会但做错、表达丢分、猜对”的学生复盘；
10. 每次掌握度变化都能追溯到具体试题证据。
