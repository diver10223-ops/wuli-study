# 电学首期建设与样板模块计划

> 决策：网站第一次实际构建从电学开始。
> 当前阶段：只完成内容边界、学习任务、题目规范、考试闭环和人工试学设计，不写网站代码。
> 首个样板模块：恒定电流与电学实验。
> 第二个验证模块：磁场、安培力与带电粒子。

## 1. 为什么首个样板选择“恒定电流与电学实验”

“从电学开始”不能理解为把全部电学内容一次性制作完成。电学内部包含静电场、电路、磁场、电磁感应、交变电流和电磁波，前置关系复杂。首个样板选“恒定电流与电学实验”，原因是：

1. 电流、电压、电阻、电源、串并联和能量关系是后续电磁内容的共同工具；
2. 它同时覆盖概念、计算、图像、仪表、实验、误差和真实电器情境，足以验证S0—S11流程；
3. 用户上传的真实试卷已经暴露出电流表改装、动态电路、支路电流、电源效率、电动机功率和实验图像等问题，可以直接作为首批真实证据；
4. 第16题“干路总电流误作电动机支路电流”是一个适合验证“考试上传—错因诊断—修复—线下复测”的明确样例；
5. 先把基础电路和实验做稳，再处理安培力、洛伦兹力和电磁综合，可以减少公式堆叠。

这不代表静电场不重要。正式课程树仍按教材和学校教学进度保留静电场前置节点；若诊断发现电势、电势差和电场力做功存在缺口，应先插入补修任务。

| E8 电磁综合 | 电路+力学+能量+动量+图像+实验 | R3及高三阶段 | 不在首轮预习中提前堆压轴题 |

### 2.2 三轨边界

- **A轨核心：**教材和北京普通高考范围内的概念、规律、实验和标准模型；
- **B轨迁移：**复杂动态电路、陌生传感器、综合实验、复合场、多过程和开放论证；
- **C轨拓展：**超出普通高考主线的连续介质推导、过度复杂电路理论或大学先修内容。

任何“高频、必考、压轴”标签都必须有教材、课标或已核验试题依据。没有依据时显示“待核验”，不能靠模型自动判断。

## 3. 首个样板模块：恒定电流与电学实验

### 3.1 样板范围

#### 核心概念

1. 电流的微观意义与定义；
2. 电压、电势差和电动势的区别；
3. 电阻、伏安特性和欧姆定律的适用条件；
4. 电源内阻、路端电压和能量转化；
5. 串联、并联、节点和回路；
6. 电功、电功率、热功率和非纯电阻用电器；
7. 电源效率和用电器效率；
8. 电表的理想化、量程、内阻和改装。

#### 核心模型

| 模型ID | 模型 | 必须掌握的动作 |
|---|---|---|
| E2-M01 | 单一闭合电路 | 选择对象，区分内外电路，写电势降落和能量关系 |
| E2-M02 | 串并联电路 | 标节点，区分干路/支路电流，检查电压关系 |
| E2-M03 | 动态电路 | 先判断等效电阻，再判断总电流、路端电压、支路量和功率 |
| E2-M04 | 含电动机电路 | 区分总电流与电动机电流，使用非纯电阻能量关系 |
| E2-M05 | 电表改装 | 明确表头满偏量、分流/分压关系和新量程 |
| E2-M06 | 电路故障 | 从电表示数、通断和节点电势逐项排除 |
| E2-M07 | 电源图像 | 从轴、截距、斜率读取电动势、内阻和工作状态 |
| E3-M01 | 多用电表 | 机械调零、欧姆调零、量程、读数、红黑表笔和使用安全 |
| E3-M02 | 测电阻 | 电路选择、系统误差、数据处理和不确定性 |
| E3-M03 | 测电动势和内阻 | 实物连接、图像处理、斜率截距、误差与方案评价 |
| E3-M04 | 传感器/二极管 | 非线性元件、极性、图像和情境信息提取 |

### 3.2 暂不放入首个样板的内容

1. 洛伦兹力圆周运动和复合场；
2. 回旋加速器、速度选择器和比荷综合；
3. 电磁感应导轨和复杂能量综合；
4. 交变电流和变压器；
5. 为了“显得难”而加入的竞赛电路。

这些内容进入E4—E8，不能混入E2的基础进度。

## 4. 首个样板的R1—R3安排

### 4.1 R1 第一轮学习/预习

**目标：**认识电路语言，建立电流、电压、电阻、电源和功率的第一版概念，不追求复杂动态电路。

#### R1任务

1. **S0诊断：**初中电路、串并联、电功率、比例和一次函数；
2. **S1地图：**`电源提供能量 → 电路分配电势差 → 电荷定向移动 → 用电器转化能量`；
3. **S2概念：**电流、电压、电阻、电动势、内阻；
4. **S3规律：**欧姆定律、串并联基本关系、闭合电路基本关系；
5. **S4基础模型：**E2-M01、E2-M02；
6. **实验预览：**认识电流表、电压表、多用电表，不进行一次性全实验灌输；
7. **即时检测：**概念6题、节点/支路4题、基础计算4题。

#### R1出口

- 能在电路图上标出节点、干路、支路和各电流；
- 能解释电压与电动势不是同一个概念；
- 基础串并联关系≥80%；
- 输出“课堂重点关注清单”，不标记稳定掌握。

### 4.2 R2 第二轮学习/同步巩固

**目标：**接入学校课堂、作业和实验，形成标准电路分析流程。

#### R2任务

1. 完成E2-M01—M07和E3-M01—M04；
2. 每道电路题先标对象、电流名称和节点关系，再列式；
3. 动态电路按“等效电阻→总电流→路端电压→支路→功率”顺序分析；
4. 实验题按“目的→原理→器材→连接→操作→读数→图像→误差→改进”组织；
5. 不定时上传作业、小测、实验报告和错题目录；
6. 每次上传形成独立考试事件和错题改进计划；
7. 执行1、3、7天复测。

#### R2出口

- 概念和适用条件≥90%；
- 单一闭合电路、串并联和动态电路基础题≥85%；
- 核心实验≥80%；
- 最近作业/小测错题均有状态明确的改进计划；
- 不再把干路总电流直接当作任一支路电流。

### 4.3 R3 第三轮学习/期中期末前

**目标：**通过真实考试完成章节出关、实验综合、混合模型识别和第一次跨章迁移。

#### R3任务

1. 先做诊断，禁止从头重复阅读全部讲义；
2. 修复复发错因：动态电路、量程内阻、图像斜率、非纯电阻功率；
3. 完成电路+实验混合限时卷；
4. 加入少量电路与磁场装置的前向连接，但不提前灌输完整E4/E5；
5. 上传期中/期末试卷，比较考前判断和真实成绩；
6. 为每个错题建立改进计划，并在下一次线下测验中验证。

#### R3出口

- 达到总设计中的章节出关线；
- 7天复测≥80%；
- 至少一项真实考试错题完成“网站复测通过→线下验证通过”；
- 能解释得分变化来自哪些模型，而不是只记录总分。

## 5. 真实考试如何接入首期建设

### 5.1 已有考试证据的映射

| 考题 | 对应节点 | 当前证据 | 进入首期的用途 |
|---|---|---|---|
| 第5题 | E2-M05电表改装 | 0分 | 建立量程与分流关系诊断题 |
| 第7题 | E2-M03动态电路 | 0分 | 验证动态分析顺序 |
| 第9题 | E2-M06电路故障 | 满分 | 作为已有能力，安排迁移复测而非重讲 |
| 第11题 | E3-M04传感器/灵敏度 | 0分 | 建立变量关系和灵敏度任务 |
| 第13题 | E3-M01/E3-M04 | 6/8 | 保留基本操作，精修极性/原理 |
| 第14题 | E3-M03 | 7/10 | 精修图像斜率、截距与方案评价 |
| 第16题 | E2-M02/E2-M04 | 5/8 | 首个错题闭环样例：总电流与支路电流 |

第2、3、4、6、8、10、12、15、17、18、19题归入E4/E5和电磁综合，不塞入首个E2/E3样板；它们将在第二个验证模块中处理。

### 5.2 首个错题闭环

以第16题第3问为首个闭环：

1. 保存原题、原解、得分和错误公式；
2. 学生确认自己当时把哪个电流当作电动机电流；
3. 回到E2-M02标节点和支路；
4. 回到E2-M04区分电功率、热功率和机械功率；
5. 完成一道同模型基础题；
6. 3天后完成不同电路结构的相邻变式；
7. 下一次校内小测观察是否再次发生支路对象错误；
8. 只有线下同类题通过，状态才改为“线下验证通过”。

## 7. 建设顺序

### P0 电学范围与学校进度核验

- 确认教材版本、学校当前教学顺序和已经学过的内容；
- 用课标、教材和北京考试文件核验A轨；
- 对已有考试题建立知识/模型映射；
- 输出“现在必须学、需要回补、后续再学”三张清单。

### P1 E2/E3内容审校

- 盘点仓库中可复用的电学内容；当前仓库主体是“运动和力”，预计电学内容缺口较大；
- 不直接用大模型批量生成全部讲义；
- 先完成概念、条件、模型和实验审校表；
- 再制作R1最小任务包。

### P2 R1人工试学

- 让孩子完成诊断、章节地图、概念和两个基础模型；
- 记录真实用时、读不懂的位置和是否需要家长导航；
- 调整后冻结R1 v1。

### P3 R2与真实错题闭环

- 制作动态电路、非纯电阻、电表和实验；
- 用第16题完成第一个错题改进计划；
- 等待一次校内作业/小测做线下验证。

### P4 R3与阶段考试

- 制作出关卷和实验综合；
- 上传真实阶段考试并重评；
- 验证系统能否回答“不会什么、为什么、下一步是什么”。

### P5 第二验证模块

- 建设E4“磁场与安培力”；
- 建设E5“洛伦兹力与带电粒子”；
- 使用本次考试第2—4、6、8、10、12、15、17—19题验证从标准模型到综合迁移。
