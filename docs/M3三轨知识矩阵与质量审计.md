# M3 相互作用与受力分析三轨知识矩阵与质量审计

## 模块边界与共享技术

M3 只处理力的性质、产生条件、方向、施力/受力对象、受力图、矢量合成分解、静态或准静态平衡、摩擦与接触临界、弹簧和绳杆约束、分布力及简单转动平衡。牛顿定律、合力与加速度、超重失重、动力学连接体、变加速和圆周动力学留给 M4 以后。C 轨只把加速参考系作为静力模型失效的边界，不系统使用非惯性系。

18 份配置继续调用既有参数化页面以及 `assets/diagnostic.js`、`assets/learning.js`、`assets/assessment.js`、`assets/progress.js`、`assets/evidence.js`、`assets/storage.js`，不复制页面或引擎。
