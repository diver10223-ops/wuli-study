# M3 相互作用与受力分析三轨知识矩阵与质量审计

## 模块边界与共享技术

M3 只处理力的性质、产生条件、方向、施力/受力对象、受力图、矢量合成分解、静态或准静态平衡、摩擦与接触临界、弹簧和绳杆约束、分布力及简单转动平衡。牛顿定律、合力与加速度、超重失重、动力学连接体、变加速和圆周动力学留给 M4 以后。C 轨只把加速参考系作为静力模型失效的边界，不系统使用非惯性系。

18 份配置继续调用既有参数化页面以及 `assets/diagnostic.js`、`assets/learning.js`、`assets/assessment.js`、`assets/progress.js`、`assets/evidence.js`、`assets/storage.js`，不复制页面或引擎。

## A轨：北京高中教材核心

| 节点    | 学习与建模范围                                    | 正式卷证据                                        |
| ------- | ------------------------------------------------- | ------------------------------------------------- |
| M3-AK01 | 力的物质性、施力/受力物体、重力、重心及匀强场边界 | 均匀圆盘重力/重心计算；托球情境辨认施力与受力物体 |
| M3-AK02 | 接触弹力、支持力/压力、轻绳拉力                   | 斜向拉力下的支持力；双绳悬挂计算                  |
| M3-AK03 | 原长、形变量、胡克定律和恢复方向                  | 压缩弹簧方向；拉伸候选力与弹性限度                |
| M3-AK04 | 静摩擦自适应、最大静摩擦、滑动摩擦                | 逐渐增大拉力的临界状态；未临界静摩擦计算          |
| M3-AK05 | 平行四边形、正交分解、共点力平衡                  | 两组不同角度的对称双绳平衡                        |
| M3-AK06 | 规范受力图、作用反作用力与平衡力                  | 支持力反作用力；书—桌情境辨析平衡力               |

A 轨正式卷门槛为 80%，核心门槛不得猜对替代。例题均明确对象、施力物体、接触、坐标或方向、数值单位、受力清单、方程结论和检查动作。

## B轨：综合迁移

| 节点    | 学习与建模范围                       | 正式卷证据                               |
| ------- | ------------------------------------ | ---------------------------------------- |
| M3-BK01 | 多接触面、叠放物体、界面力           | 两层接触的地面支持力；两接触面支持力联算 |
| M3-BK02 | 三力平衡、图解/解析与缓慢变化        | 斜绳—水平约束平衡；改变角度时张力趋势    |
| M3-BK03 | 斜向拉力、摩擦临界、N≥0与状态切换    | 支持力变化后的最大静摩擦；联立求临界拉力 |
| M3-BK04 | 整体法与隔离法的边界                 | 隔离上块求内摩擦；由整体切换隔离法       |
| M3-BK05 | 绳、杆、弹簧、理想定滑轮             | 杆力方向；定滑轮—弹簧限度与张紧检查      |
| M3-BK06 | 测力计、摩擦实验、误差方向和证据限度 | 证据边界判断；零点误差定量修正           |

B 轨正式卷门槛为 75%。所有静摩擦题先由平衡求所需值，再检查 `|f静|≤μsN`；支持力检查 `N≥0`，轻绳检查张紧和 `T≥0`，弹簧检查弹性限度。整体法只求外力，内力返回隔离法。

## 六阶段差异与内容自查

- 诊断只检查重力方向、接触弹力、形变量、矢量分量、静摩擦范围等必要前置，不复制正式卷。
- 学习的 `summary` 讲规律，`conditions` 限定模型，`misconception` 解释具体错误，`example` 给可核验的新情境，`check` 给逐项施力、代回方程或约束检查动作。
- 模型用另一装置执行“隔离对象→接触与施力者→坐标/取矩点→平衡方程→候选量→物理约束→情境解释”的完整链。
- 即时检测每轨8题并覆盖六节点；正式卷每轨12题、每节点各2题，分别留下概念/条件证据与计算/建模证据，且 `task` 与节点尾码一致；复测每轨6题覆盖全部六节点，并使用不同装置与推理入口。
- 三轨的诊断、即时检测、正式卷和复测均打散正确答案位置；归一化审计同时剔除数字、单位和常见对象名，防止仅换数字或名称制造“新题”。
- 编写者逐项核对18份文件中的受力对象、真实力、方向、形变量、摩擦类型、矢量运算、完整平衡、相互作用力、非负约束、单位、答案索引和跨阶段题干差异。
