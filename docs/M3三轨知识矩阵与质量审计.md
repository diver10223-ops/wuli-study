# M3 相互作用与受力分析三轨知识矩阵与质量审计

## 模块边界与共享技术

M3 只处理力的性质、产生条件、方向、施力/受力对象、受力图、矢量合成分解、静态或准静态平衡、摩擦与接触临界、弹簧和绳杆约束、分布力及简单转动平衡。牛顿定律、合力与加速度、超重失重、动力学连接体、变加速和圆周动力学留给 M4 以后。C 轨只把加速参考系作为静力模型失效的边界，不系统使用非惯性系。

18 份配置继续调用既有参数化页面以及 `assets/diagnostic.js`、`assets/learning.js`、`assets/assessment.js`、`assets/progress.js`、`assets/evidence.js`、`assets/storage.js`，不复制页面或引擎。

## 六阶段差异与内容自查

- 诊断只检查重力方向、接触弹力、形变量、矢量分量、静摩擦范围等必要前置，不复制正式卷。
- 学习的 `summary` 讲规律，`conditions` 限定模型，`misconception` 解释具体错误，`example` 给可核验的新情境，`check` 给逐项施力、代回方程或约束检查动作。
- 模型用另一装置执行“隔离对象→接触与施力者→坐标/取矩点→平衡方程→候选量→物理约束→情境解释”的完整链。
- 即时检测每轨8题并覆盖六节点；正式卷每轨12题、每节点各2题，分别留下概念/条件证据与计算/建模证据，且 `task` 与节点尾码一致；复测每轨6题覆盖全部六节点，并使用不同装置与推理入口。
- 三轨的诊断、即时检测、正式卷和复测均打散正确答案位置；归一化审计同时剔除数字、单位和常见对象名，防止仅换数字或名称制造“新题”。
- 编写者逐项核对18份文件中的受力对象、真实力、方向、形变量、摩擦类型、矢量运算、完整平衡、相互作用力、非负约束、单位、答案索引和跨阶段题干差异。
