# E6电磁感应三轨知识矩阵与考卷规格

## 三轨边界

- A轨：磁通量、感应条件、楞次方向、法拉第定律、切割、电路与能量。
- B轨：双棒、含容暂态、线框穿场、转动切割、制动、图像与综合。
- C轨：互感自感、RL暂态、场能、涡流近似、数值思想与探究。
