# M5 曲线运动与圆周运动三轨知识矩阵与质量审计

## 三轨内容

- A轨（基础核心）：曲线运动条件、运动合成分解、平抛运动、圆周运动量、向心加速度与向心力、平抛圆周实验；正式卷门槛80%。

- B轨（迁移拔高）：斜面平抛、平抛临界、竖直圆周临界、绳杆轨道约束、关联运动、圆周与能量综合；正式卷门槛75%。

- C轨（强基先修）：斜抛参数方程、轨迹包络最值、极坐标描述、非匀速圆周、曲率与法向加速度、旋转系初步；正式卷门槛70%。

## 统一流程

每轨均包含诊断、学习、模型、即时检测、正式卷和间隔复测；正式卷和复测都通过才表示稳定。B/C不能补偿A轨。
