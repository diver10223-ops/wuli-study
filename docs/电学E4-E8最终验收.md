# 电学E4—E8最终验收

## 范围验收

E4磁场与安培力、E5洛伦兹力、E6电磁感应、E7交变电流与电磁波、E8电磁综合均已建立A/B/C三轨。每轨均有诊断、知识任务、模型任务、即时检测、正式卷、间隔复测和本地证据。

## 产品验收

- 根入口进入电学总中心；E4—E8均可从总中心访问。
- 各模块总进度可导出JSON；全电学进度页汇总模块正式卷与复测状态。
- 前置证据不足时仅可预览，不能形成正式通过。
- 正式卷保存分项、门槛、薄弱任务和复测日期。
- 未核验内容不宣称北京真题或必考；C轨不替代普通高考主线。

## 尚需人工完成

功能和结构验收通过不等于教学发布审核。正式供孩子长期使用前，仍需教师逐题核验、真实手机试学、教材版本确认和真实考试外部验证。
