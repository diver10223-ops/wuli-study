# E2/E3三轨全流程质量审计

## 1. 审计范围

本轮审计覆盖E2/E3三轨入口、A基础卷、B准入/学习/即时检测/拓展卷、C准入/学习/即时检测/强基卷，以及这些页面使用的本地学习证据。

## 2. 路由审计

| 路线 | 当前状态 | 判定 |
|---|---|---|
| A学习 → A基础卷 | 已接通 | A卷与R3周期卷明确分开 |
| A通过 → B学习 | 已接通 | B学习包读取A卷证据 |

| C学习 → 即时检测 → C强基卷 | 已接通 | 正式卷需要人工审核书面证据 |

## 3. 本轮发现并修复的问题

### 3.1 预览模式仍会保存任务

此前B、C学习包虽然显示“尚未准入”，但复选框仍可操作，可能让预览者生成正式学习进度。本轮已改为：未准入时禁用任务复选框，不初始化该轨道的任务存储，只显示预览提示。

### 3.2 证据跨轨误标风险

三轨入口已分别读取A卷、B卷、C诊断和C卷状态，并明确低轨证据不能冒充高轨通过。C卷未完成书面人工审核时显示“待审核”。

### 3.3 自动评分不适合强基书面任务

C卷采用客观题自动评分和书面题人工评分结合。书面题需要保存纸面原稿，探究题另外核验假设、变量、可测预测、判据和局限，未审核时不判通过。

## 4. 自动审计

仓库新增`tests/audit_electric.py`，无需第三方Python依赖，检查：

1. E2页面是否包含移动端viewport；
2. HTML ID是否重复；
3. 本地导航是否断链；
4. 内联JavaScript能否通过`node --check`；
5. 三轨入口是否包含全部正式路线；
6. A/B/C关键通过规则是否仍然存在。

运行命令：

```bash
python3 tests/audit_electric.py
```

## 5. 尚未解决的限制

1. 数据只保存在当前浏览器，清理浏览器数据后会丢失；
2. 没有账号、跨设备同步、导出或备份；
3. 家长/教师人工评分身份尚无服务端认证；
4. 尚未完成真实手机浏览器和屏幕阅读器测试；
5. 题目仍需教材版本、学科教师和考试范围审核；
6. 当前自动审计属于结构与规则回归测试，不等同学科正确性审核。

## 6. 下一步计划

### 现在做什么

建立E1静电场的A/B/C知识矩阵和考卷规格，不直接复制E2/E3题目或页面。

### 迁移前提

E1必须先明确电荷、库仑定律、电场强度、电势、电势差、电势能、电容器和带电粒子的分轨边界，再建设页面；不得把强基推导混入A轨。
