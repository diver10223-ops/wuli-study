# E1静电场三轨全流程质量审计

## 1. 审计结论

E1已形成A基础、B拓展、C强基三轨首版闭环。三轨深度与学习轮次是两个不同维度：A/B/C表示内容深度，诊断、学习、检测、考试与复测表示时间流程，不能互相替代。

## 2. 路由与门槛

| 路线 | 正式证据 | 未通过后的返回 |
|---|---|---|
| A诊断 → 知识卡 → 模型 → A卷 | A卷总分、分项和关键门槛 | 只返回对应A节点 |
| A通过或B直接诊断 → B学习 → 检测 → B卷 | B卷总分、多过程、电容动态、陌生题独立完成 | 优先返回B任务，证据显示基础错误才回A |
| B通过 → C诊断 → C学习 → 检测 → C卷 | B证据、工具门槛、明确目标、人工审核书面任务 | 返回对应C任务或缺失的工具节点 |

## 3. C轨边界

1. C轨不是北京普通高考默认任务，不得挤占A/B和校内任务；
2. C轨准入需要B轨通过、工具诊断通过和明确的强基/竞赛衔接/大学先修目标；
3. C卷不能只靠客观题自动通过，必须保留推导和探究原稿并完成人工审核；
4. C轨通过只表示当前阶段证据成立，仍需新情境和间隔复测。

## 4. 数据审计

E1页面使用`physics-e1-{track}-{activity}-v1`形式的本地存储键。进度页只读取这些键，不把低轨记录冒充高轨证据，也不上传学生数据。导出文件包含模式名、版本、导出时间和各项原始记录，供备份与后续迁移。

当前限制：本地记录可以被浏览器使用者修改；人工审核者没有账号认证；导出文件不加密；系统尚不能跨设备同步。因此这些记录属于学习辅助证据，不能替代正式学校成绩。

## 5. 迁移到E4前的冻结规则

1. 先建立E4知识矩阵，再建立页面；
2. A轨只放普通高考核心，B轨放复杂迁移，C轨单独准入；
3. 真实错题只能映射到知识节点，不能决定课程目录；
4. 每轨必须有诊断、学习、检测、正式考卷和精确返回路线；
5. 强基书面任务继续采用人工审核，不伪装成自动评分；
6. 页面必须通过结构审计、链接审计和JavaScript语法检查。

## 6. 下一步

以本审计和E1知识矩阵为模板，先建立E4“磁场与安培力”三轨知识矩阵与考卷规格，不直接复制E1题目。
