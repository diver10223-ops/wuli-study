# 物理知识模块统一开发标准

## 1. 适用范围

本标准适用于力学、电学以及后续热学、振动与波、光学、近代物理等全部知识模块。电学E1—E8是已实现的结构基线，后续模块不得另建不兼容的学习流程。

## 2. 每个模块的强制结构

每个知识模块必须提供：模块入口、A/B/C三轨入口、模块进度页、知识矩阵、质量审计和来源说明。每一轨必须具有六个独立阶段：

1. `diagnostic`：前置或准入诊断；
2. `learning`：知识学习；
3. `models`：模型训练；
4. `check`：即时检测；
5. `exam`：正式出关卷；
6. `retest`：间隔复测。

缺少任一阶段时只能标记为“建设中”，不得显示“三轨闭环”或“已经完成”。

## 3. 三轨规则

- A轨是教材与普通高考核心，必须独立达标。
- B轨是复杂情境与迁移拔高，不能补偿A轨未通过。
- C轨是强基、竞赛衔接和大学先修，显式导数、积分等超前工具不得混入A轨。
- 三轨都使用六阶段闭环，但题目范围、通过条件和人工审核要求相互独立。

## 4. 证据与进度

存储键统一为`physics-{domain}-{module}-{track}-{stage}-v1`。力学使用`physics-mechanics-*`，电学保留`physics-e*`兼容键。总进度只读取本机证据；正式卷和复测均通过才表示该轨稳定，不因页面存在而自动完成。

## 5. 开发与资源控制

开发时先运行当前模块的小范围审计；一个阶段完成后才运行一次全域回归。禁止为了静态页面检查长期启动服务器、浏览器或重复安装依赖。完整审计放在提交前执行一次，并在`执行结果.md`记录实际结果。

## 6. 验收门槛

- 所有页面有移动端viewport且内部链接有效；
- JavaScript和数据配置通过语法检查；
- A/B/C边界、通过分数、关键门槛和人工审核规则明确；
- 进度页能读取、区分和导出三轨六阶段证据；
- 未完成内容明确标注，不用空壳页面冒充课程内容；
- 教师审校、真实设备试学和真实考试验证单独记录，不以结构审计代替。
