# M7 功、能量与机械能三轨知识矩阵与质量审计

## 三轨内容

- A轨（基础核心）：功与功的正负、功率、动能定理、势能、机械能守恒、功能关系与实验；正式卷门槛80%。

- B轨（迁移拔高）：变力功图像、机车启动、传送带能量、板块耗散、圆周能量临界、多过程功能关系；正式卷门槛75%。

- C轨（强基先修）：功的积分、势能曲线、稳定平衡、有效势能、参数能量模型、数值能量检验；正式卷门槛70%。

## 统一流程

每轨均包含诊断、学习、模型、即时检测、正式卷和间隔复测；正式卷和复测都通过才表示稳定。B/C不能补偿A轨。
