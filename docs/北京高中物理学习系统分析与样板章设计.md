# 北京高中物理学习系统分析与样板章设计

> 文档性质：历史资料盘点、课程结构设计与产品规则，不包含网站代码。
> 当前样板范围：`运动和力/` 目录及“匀变速直线运动”。
> 编制日期：2026-07-27。

## 0. 执行结论

现有资料已经具备“讲义、进阶、易错题、检测卷、答案、打印稿”六类资产，但仍以静态打印页为中心。下一阶段应停止无边界扩充资料，先把内容放入统一课程树，并用“诊断—学习—检测—纠错—复习”闭环组织。

本轮形成五项成果：

1. 逐文件盘点 `运动和力/` 下 54 项资料；
2. 建立北京高中物理课程树和三轨边界；
3. 定义每章统一的十二步学习流程；
4. 定义进度、掌握度、错因与复习调度规则；
5. 完成“匀变速直线运动”样板章的内容设计。

在上述五项基础上，学习时间轴进一步明确为“正常学习三轮 + 高三复习三轮”。现阶段优先把R1预习、R2同步巩固、R3期中期末前学习做实，并让每次学校试卷和错题上传都能触发重新评估与错题改进计划。

项目实施顺序现已调整为**从电学开始**。本文件中的“匀变速直线运动”保留为早期方法设计样例，不再是首个实际构建章节，也不作为电学内容完成前的开发前置条件。首期实施以[电学首期建设与样板模块计划](电学首期建设与样板模块计划.md)为准。

需要特别说明：课程树按现行新教材常用结构整理，但本环境未能连接官方检索接口。教材版本、北京当年教学安排、选考范围和真题证据在正式发布前必须由“课标原文 + 北京教育考试院文件 + 学校实际教材”三方核验；未核验内容不得显示为“北京必考”。

### 1.1 盘点规则

每项资料按以下处置状态标记：

- **保留**：内容定位清楚，可直接进入内容资产库；
- **拆分**：内容有价值，但需拆成可检测的小任务；
- **合并**：与其他文件高度重叠，应确定唯一主版本；
- **转轨**：从北京高考核心主线移入拔高或强基轨；
- **核验**：学科表述、范围、来源或答案需要复核；
- **打印附件**：作为离线打印版本保留，不作为独立课程节点。

### 1.4 重复、缺口与优先修复

**主要重复：**

1. `运动和力的关系.html` 与 `运动和力的关系2.html` 双版本；

**主要缺口：**

1. 无课前诊断和明确先修关系；
2. 无逐知识点即时检测；
3. 无独立作答、用时、提示使用记录；
4. 无章节准入/出关标准；
5. 无错题重做和间隔复习；
6. 无真题来源、年份、地区、题号和核验状态；
7. 无统一入口、章节路线和下一步推荐；
8. 无A/B/C轨道隔离。

## 2. 北京高中物理章节树

### 2.1 三条学习轨道

| 轨道 | 定位 | 是否计入普通高考主进度 | 示例 |
|---|---|---:|---|
| A 北京高考核心 | 课标、教材和北京考试要求内的必备知识与核心能力 | 是 | 匀变速、受力、牛顿定律、能量、动量、电磁场、实验 |
| B 高考迁移与拔高 | 课标内陌生情境、综合模型、多方法、开放探究 | 达到基础线后计入 | 关联速度、多过程临界、创新实验、跨模块综合 |
| C 强基/竞赛/大学先修 | 非普通高考默认要求或使用超前数学工具 | 否 | 显式求导积分、微分方程、系统斜抛理论 |

任何节点必须包含 `轨道`、`依据`、`核验状态`。一个知识点即使在C轨完成，也不能补偿A轨未达标。

### 2.2 课程主树（发布前待官方核验）

#### 必修第一册：运动与相互作用

1. **运动的描述**
   - 质点、参考系、时间与位移；
   - 位置、位移、速度；
   - 加速度；
   - 打点计时器/数字化手段测速度。
2. **匀变速直线运动**
   - 模型条件与速度—时间关系；
   - 位移—时间关系；
   - 图像；
   - 自由落体；
   - 研究匀变速运动实验。
3. **相互作用——力**
   - 重力、弹力、摩擦力；
   - 牛顿第三定律；
   - 力的合成与分解；
   - 受力分析。
4. **运动和力的关系**
   - 牛顿第一、第二定律；
   - 单位制；
   - 动力学两类问题；
   - 超重与失重；
   - 探究加速度与力、质量的关系。

#### 必修第二册：曲线运动、天体与能量

5. **抛体运动**：曲线运动、运动合成分解、平抛；斜抛按考试范围分轨。
6. **圆周运动**：线速度、角速度、向心加速度、向心力、生活模型。
7. **万有引力与宇宙航行**：开普勒规律、万有引力、天体运动、卫星与航天。
8. **机械能守恒**：功、功率、动能定理、势能、机械能守恒、功能关系。

#### 必修第三册：电磁学基础与能源

9. **静电场及其应用**：电荷、库仑定律、电场、电场强度、静电平衡。
10. **静电场中的能量**：电势、电势差、电势能、电容器、带电粒子。
11. **恒定电流**：电源、电流、电阻、串并联、闭合电路、用电安全与实验。
12. **电磁场与电磁波初步**：磁场、磁感应强度、电磁场、电磁波。
13. **能源与可持续发展**：能量转化、能源利用、环境与社会责任。

#### 选择性必修第一册：动量、振动、波与光

14. **动量与动量守恒**：冲量、动量定理、守恒条件、碰撞、反冲。
15. **机械振动**：简谐运动、单摆、能量、受迫振动与共振。
16. **机械波**：波的形成、图像、波速、干涉、衍射、多普勒效应。
17. **光**：折射、全反射、干涉、衍射、偏振。

#### 选择性必修第二册：电磁感应与交变电流

18. **安培力与洛伦兹力**：磁场对电流和运动电荷的作用。
19. **电磁感应**：感应条件、楞次定律、法拉第定律、自感。
20. **交变电流**：产生、描述、变压器、电能输送。
21. **电磁振荡与电磁波**：振荡电路、电磁波谱与应用。

#### 选择性必修第三册：热学与近代物理

22. **分子动理论**：分子运动、相互作用、内能。
23. **气体、固体和液体**：气体规律、固体液体性质。
24. **热力学定律**：热力学第一、第二定律与能量方向性。
25. **原子结构和波粒二象性**：原子模型、光电效应、物质波。
26. **原子核**：核结构、衰变、核反应、核能与辐射安全。

#### 贯穿式能力树（不单独当一章）

1. 实验设计、器材、操作、数据、图像、误差、改进；
2. 建模：对象—过程—条件—规律—方程—检验；
3. 数学工具：比例、函数、方程、几何、三角、图像、极限和微元思想；
4. 表达：符号、方向、单位、有效数字、原始公式、评分点；
5. 信息题：读取材料、筛选条件、迁移规律、论证结论；
6. 跨章融合：力学、电磁、能量、动量、实验与现代科技。

### 2.3 当前“运动和力”资料的归位

- `运动的描述`、`匀变速直线运动`、`相互作用——力`、`运动和力的关系` → 必修第一册A轨；
- `代数和图像研究运动` → 贯穿式方法，A/B轨分层；
- `微元法` → B/C轨；
- `导数`、`定积分` → C轨；
- `平抛`、`圆周运动` → 必修第二册对应章节；
- `斜抛` → 范围核验后进入B/C轨；
- `关联运动` → B轨跨章专题；
- “第1章物体的运动”总览 → 改名为“运动学模块深化地图”。

## 3. 统一章节学习流程

每章固定十二步，编号稳定，页面名称可因章节调整。

| 步骤 | 名称 | 学生动作 | 必须记录 | 出口条件 |
|---:|---|---|---|---|
| S0 | 学情诊断 | 独立完成前置、概念和数学工具小测 | 正误、用时、信心、错因 | 生成个性化起点，不要求满分 |
| S1 | 章节地图 | 说出本章核心问题和前后联系 | 浏览后口述/选择结果 | 核心关系题通过 |
| S2 | 概念建立 | 观察现象、形成定义、辨析正反例 | 复述、反例、即时题 | 概念即时检测≥90% |
| S3 | 规律与边界 | 理解规律、条件、方向、单位和图像 | 条件判断、公式选择 | 条件题≥90%，关键公式能解释 |
| S4 | 单模型示范 | 按对象—过程—图—规律—方程—检验完成例题 | 是否独立、提示级别、步骤缺失 | L1题≥85% |
| S5 | 标准变式 | 改数据、方向、设问、表征和约束 | 首次正确率、用时 | L2题≥80% |
| S6 | 实验与探究 | 设计、操作推理、数据处理、误差改进 | 分项评分 | 核心实验≥80%，关键安全项全对 |
| S7 | 易错修复 | 识别错解、归因、完成相邻变式 | 错因、修复节点、重做日期 | 同错因变式连续2次通过 |
| S8 | 满分能力 | 多对象、多过程、临界、多解、陌生情境 | 评分点、提示、限时 | 基础达标后解锁；不作为所有人强制 |
| S9 | 章节出关 | 完成概念、模型、实验和限时综合检测 | 分项成绩与非知识失分 | 见第4节出关规则 |
| S10 | 间隔复习 | 在到期日完成混合小测和核心错题 | 遗忘情况、重做表现 | 1/3/7/14/30天稳定 |
| S11 | 融合迁移 | 章内综合、跨章专题和真题 | 关联模块、模型选择、评分点 | 对应阶段专题达标 |

### 3.1 六轮学习周期与十二步的关系

“六轮学习周期”是时间轴，“S0—S11”是每一轮内部按需调用的学习动作。六轮不是把同一套讲义重复看六遍，而是每轮使用不同证据、目标和任务深度重新评估。当前建设优先完成前三轮正常学习；高三三轮复习只先保留接口和规则，待正常学习体系验证后再详细建设。

| 周期 | 名称 | 建议发生时间 | 核心目标 | 主要调用步骤 | 本轮完成证据 |
|---:|---|---|---|---|---|
| R1 | 第一轮学习/预习 | 学校正式讲授前 | 建立现象、概念和章节地图，暴露前置漏洞 | S0—S4，少量S6 | 预习诊断、概念复述、基础题；不以高难度为目标 |
| R2 | 第二轮学习/同步巩固 | 学校讲授后或单元学习期间 | 修正第一次理解，形成模型和标准步骤 | S2—S7、S10 | 作业/小测、模型题、实验、错因修复和间隔复测 |
| R3 | 第三轮学习/期中期末前 | 阶段考试前 | 章节出关、章内融合和第一次跨章迁移 | S7—S11 | 阶段卷、学校期中/期末卷、限时表现和考后改进计划 |
| R4 | 高三一轮复习 | 高三系统复习 | 重建全知识网络，补齐A轨漏洞 | S0、S3—S11 | 章节/模块卷、真题、校内考试和稳定掌握证据 |
| R5 | 高三二轮复习 | 专题复习阶段 | 跨章专题、能力短板、综合模型迁移 | S7—S11 | 专题卷、综合卷、速度与评分点表现 |
| R6 | 高三三轮复习 | 高考冲刺阶段 | 套卷仿真、时间策略、稳定性和止损 | S7、S9—S11 | 全真套卷、考试波动、非知识性失分和状态管理 |

#### R1 第一轮学习/预习

- 先做S0，不把“没学过所以不会”简单记成错误；重点判断数学工具和前置概念；
- 用S1建立全章问题地图，用S2形成第一版概念，用S3认识最少核心规律；
- S4只做单模型基础题，实验以观察目的、变量和现象为主；
- 本轮允许“尚未掌握”，但必须记录疑问，供学校课堂和R2验证；
- 结束时输出“课堂重点关注清单”，而不是满分结论。

#### R2 第二轮学习/同步巩固

- 导入学校课堂、作业、小测和老师批改信息，修正R1形成的错误理解；
- 完成S3—S6的规律、模型、变式和实验，重点建立标准解题步骤；
- 对作业和小测错误执行S7，不允许只订正答案；
- 开始S10间隔复习，并用学校下一次小测检验修复是否迁移；
- 达标者可少量进入S8，未达标者不得用难题替代基础修复。

#### R3 第三轮学习/期中期末前

- 不重新通读整章，先用阶段诊断定位遗忘点和反复错因；
- 完成S9章节出关、S11章内融合，并逐步加入已学章节的跨章混合题；
- 使用期中/期末前的校内模拟卷训练限时、表达和时间分配；
- 正式考试后必须上传试卷或错题目录，生成单次考试改进计划；
- R3完成以“正式线下考试证据 + 改进计划闭环”为准，不只看网站练习分数。

#### R4—R6 高三三轮复习（后续建设）

- R4按章节和模块重新诊断，允许跳过已有稳定证据的内容，但不能凭主观感觉跳过；
- R5不再按教材顺序重复讲解，按图像、实验、多对象、多过程、电磁综合等能力专题组织；
- R6以北京卷结构的全真限时、时间策略、稳定性和非知识性失分为主；
- 每轮都必须接入学校考试证据并更新掌握度，但不能因为一次偶然高分永久覆盖长期薄弱记录。

### 3.2 答案与解析六级呈现

1. 最终答案；
2. 审题方向；
3. 研究对象与过程提示；
4. 核心模型/规律提示；
5. 关键方程与评分点；
6. 完整解析、合理性检查、错因和变式。

系统必须记录学生打开的最高提示级别。看完整解析后“看懂”只计为“已学习”，不能计为“独立掌握”。

### 3.3 试卷/错题上传与单次考试跟进闭环

上传不是附加功能，而是贯穿R1—R6的现实证据入口。学生可以不定时上传学校作业、小测、周测、月考、期中期末卷、模拟卷、正式考试卷或手工错题目录。每次上传都形成一个独立的“考试事件”，不能把多次考试混成一份模糊错题本。

#### 可上传内容

1. 完整试卷：题目页、学生作答页、教师批改页、答案/评分标准（如有）；
2. 部分错题：清晰题目、本人原解、教师批注和正确答案；
3. 错题目录：题号、章节、得分、错误原因和照片索引；
4. 考试信息：考试名称、日期、满分、得分、时长、年级/班级范围、是否限时完成；
5. 学生复盘：不会、会但做错、来不及、表达丢分、猜对等主观判断。

#### 自动分析流程

`上传 → 图像/文本完整性检查 → 题目切分 → 识别作答与批改 → 人工确认 → 知识/模型/能力标签 → 错因诊断 → 掌握度重评 → 生成错题改进计划 → 复测 → 下一次线下考试验证`

系统自动识别结果必须允许学生或家长确认。题目不清、批改符号不明、题目来源无法识别时标记“待确认”，不得自动编造题干、答案、分数或错误原因。

#### 单次考试报告

每次考试至少输出：

- 总分、各题得分、各章节/模型/能力得分；
- 应得但丢失的分数、暂不会的分数和时间不足导致的分数；
- 新错误、复发错误、已修复但本次反弹的错误；
- 知识性失分、过程性失分和考试策略失分；
- 本次结果相对系统原掌握度的支持或冲突；
- 需要立即处理、可以延后和暂不处理的事项；
- 本次错题改进计划及下一次线下验证点。

#### 错题改进计划（每次考试必有）

| 字段 | 要求 |
|---|---|
| 计划ID | 与考试事件和原题ID绑定 |
| 原始证据 | 原题、原解、批改、得分和用时 |
| 错因结论 | 学生自评 + 系统分析 + 必要时人工确认 |
| 修复节点 | 精确到概念、条件、模型、实验或表达步骤 |
| 改进行动 | 重学卡、错解辨析、同模型基础题、相邻变式或限时训练 |
| 完成标准 | 不看答案独立做对、解释条件并达到目标用时 |
| 复测安排 | 当日订正，1/3/7/14/30天按严重程度选择 |
| 线下验证 | 指定下一次作业、小测或考试中的观察指标 |
| 状态 | 待确认、待修复、修复中、网站复测通过、线下验证通过、再次复发 |

“抄写正确答案”不能完成改进计划。至少需要完成错因确认和一次不看解析的相邻题复测；只有后续真实线下考试中同类题再次通过，才能标记“线下验证通过”。

仓库中的[单次考试分析与错题改进计划样例](单次考试分析与错题改进计划样例.md)使用一份真实高一物理诊断卷演示了考试事件、逐题诊断、掌握度重评、四类改进包、两周安排和下一次考试验证指标。

## 4. 进度与掌握度规则

### 4.1 五类状态必须分开

| 状态 | 回答的问题 | 示例 |
|---|---|---|
| 内容进度 | 看过或做过多少？ | 8/12任务完成 |
| 执行质量 | 是否按要求独立、限时完成？ | 80%任务未看解析先作答 |
| 当前掌握 | 现在能否正确解决？ | 模型掌握78 |
| 稳定掌握 | 间隔后是否仍会？ | 14天复测通过 |
| 迁移能力 | 换情境后是否会选模型？ | 跨章题70 |

禁止把“页面已读100%”显示成“掌握100%”。

### 4.2 任务状态机

每个任务只能处于以下状态之一：

`未开放 → 待学习 → 学习中 → 待检测 → 已通过 → 待复习 → 稳定掌握`

辅助状态：`需回炉`、`已跳过（诊断证明掌握）`、`选学`、`待教师核验`。

### 4.3 掌握度建议算法

每个知识/模型节点满分100：

| 证据 | 权重 |
|---|---:|
| 概念与条件检测 | 20% |
| 基础模型首次独立正确 | 25% |
| 标准变式迁移 | 20% |
| 实验/图像/表达（适用时） | 10% |
| 限时综合表现 | 10% |
| 间隔重做 | 15% |

规则：

1. 使用完整解析后做对，该题本次独立得分上限为40%；
2. 使用提示1/2/3/4/5级时，该题证据系数建议为0.9/0.8/0.7/0.6/0.5；
3. 猜对或无法解释的选择题不计“概念已掌握”；
4. 实验不适用的节点，将该10%按比例分配给概念与变式，不强行填实验；
5. C轨成绩不进入A轨掌握度；
6. 只有完成间隔复测，才能标记“稳定掌握”。

### 4.4 章节出关规则

建议初始阈值（后续按孩子情况校准）：

- A轨关键概念与条件 ≥ 90%；
- L1基础模型 ≥ 85%；
- L2标准变式 ≥ 75%；
- 核心实验 ≥ 80%；
- 章节限时卷 ≥ 75%；
- 所有“致命错因”（对象、方向、守恒/定律条件）均完成修复题；
- 至少一次7天后复测 ≥ 80%。

任何单项低于60%，即使总分达线也不能出关；系统应定位薄弱节点而不是要求整章重学。

### 4.5 错因分类

一级类别固定，二级类别随章节扩展：

1. 概念定义；
2. 适用条件；
3. 研究对象；
4. 过程划分；
5. 方向/矢量；
6. 模型或规律选择；
7. 图像与表征；
8. 实验原理/操作/数据/误差；
9. 数学变形与计算；
10. 单位、有效数字与表达；
11. 审题和信息遗漏；
12. 时间管理与策略。

学生自选错因后，系统用一道诊断题复核。不能把所有错误都自动归为“粗心”。

### 4.6 复习调度

首次建议间隔为1、3、7、14、30天：

- 独立且快速通过：下次间隔扩大；
- 做对但超时/低信心：间隔不变；
- 使用提示后做对：缩短一级；
- 做错且同错因复发：立即回到修复节点，并在1天后重做；
- 连续两次间隔复测通过：标为稳定；
- 30天复测通过后进入月度混合练习，不再重复整套讲义。

### 4.7 家长与学生报告

**学生端**显示今日任务、下一步、到期复习、具体薄弱点，不强调排名。
**家长端**显示计划执行率、有效学习时长、首次正确率、提示依赖、反复错因、稳定掌握章节和下周建议。
**教师/内容审核端**额外显示题目区分度、异常答案、来源待核验和内容错误反馈。

#### 所有输出必须包含“下一步计划”

网站报告、学习任务、考试分析、错题改进、家长周报以及项目设计文档，每次输出末尾都必须给出明确的“下一步计划”，不能只总结已经完成的内容。下一步计划至少包含：

1. **现在做什么：**一个可以立即开始的首要任务；
2. **为什么先做：**该任务对应的证据、薄弱点或前置依赖；
3. **具体产出：**完成后得到的文档、任务包、复测结果或掌握证据；
4. **完成标准：**怎样判断任务真正完成，而不是只浏览过；
5. **预计时间：**建议开始时间、单次时长或完成周期；
6. **需要的材料：**如教材版本、学校进度、试卷、答案、批改或学生反馈；
7. **完成之后：**通过时进入什么任务，未通过时返回哪个节点。

默认只突出一个最高优先级的立即任务，其余内容放入“随后安排”，避免一次输出十几个并列待办导致无法执行。

### 4.8 六轮进度与线下考试重评规则

每个章节同时记录“轮次进度”和“知识节点掌握”，两者不能互相替代。例如R2已经完成，只代表同步学习任务执行完，不代表该章稳定掌握；R3期中考试暴露漏洞后，R2相关节点可以重新进入“需回炉”，但R2历史记录不能被删除。

#### 每轮进度字段

| 字段 | 示例 |
|---|---|
| 当前轮次 | R2 第二轮学习/同步巩固 |
| 本轮任务进度 | 14/18 |
| 本轮开始/目标完成日 | 9月10日 / 9月24日 |
| 本轮独立正确率 | 78% |
| 本轮主要错因 | 正方向、刹停边界 |
| 本轮线下证据 | 周测2、月考1 |
| 本轮状态 | 进行中/已完成/需回炉 |
| 下一轮准入 | 完成月考改进计划并通过7天复测 |

#### 掌握度重评原则

1. 网站内练习提供高频、细粒度证据，真实限时线下考试提供更高真实性证据；两者分别保存；
2. 一次考试结果只更新本次覆盖的知识和模型，不得把总分粗暴分摊到全部章节；
3. 原来显示“稳定掌握”的节点在线下考试中同类错误复发，应降为“需回炉”，并新建错题改进计划；
4. 线下做对但存在猜测、过程错误或教师未给过程分时，不直接认定独立掌握；
5. 题目超出当前轨道、题面有误或批改存疑时，先标记待核验，不影响掌握度；
6. 单次低分不永久否定历史表现，系统同时显示最近表现、滚动趋势和最佳稳定证据；
7. 系统建议必须允许家长/教师纠正，并保留修订原因和时间；
8. 每次重评后都必须说明“哪些指标变化、依据哪道题、下一步为何改变”，避免黑箱分数。

#### 建议的证据优先级

同一知识节点发生冲突时，优先参考：

`近期正式限时考试的独立作答 > 近期校内小测/作业的独立作答 > 网站限时混合测验 > 网站同类集中练习 > 看提示后的完成结果`

优先级不是固定加权公式。若正式考试只有一道偶然题，仍应结合多次证据；系统需要显示置信度为“证据不足、初步判断、较稳定、稳定掌握”。

## 5. “匀变速直线运动”完整样板章设计

### 5.1 章节定位

- 所属：必修第一册，A轨核心；
- 建议对象：高一同步、期中复习、高三一轮回补；
- 前置知识：位移、速度、加速度、坐标与正方向、一次函数和图像斜率；
- 后续连接：自由落体、牛顿第二定律、多过程运动、能量、实验图像处理；
- 当前可复用资产：`物理笔记：匀变速直线运动.html`、`匀变速直线运动 · 满分冲刺（第3页）.html`、第2讲代数与图像资料、常错题和检测卷。

### 5.2 学习目标

学生完成后应能：

1. 从“加速度恒定”判断匀变速模型，而不是从“速度均匀”猜测；
2. 明确正方向并正确处理初速度、加速度、位移的符号；
3. 从基本关系选择或推导适合的公式，不机械套公式；
4. 在文字、运动示意图、`v-t`图、`x-t`图和代数式间转换；
5. 解决单阶段与多阶段、追及相遇和刹车停止问题；
6. 设计/理解研究匀变速运动实验并处理数据、分析误差；
7. 用方向、单位、极限、图像和数量级检查答案；
8. 在基础达标后处理临界、分段、陌生情境与规范表达。

### 5.3 样板章任务清单

#### S0 诊断（10—15分钟）

| 任务 | 内容 | 诊断目的 |
|---|---|---|
| D1 | 区分速度、速度变化量、加速度 | 概念前置 |
| D2 | 给定正方向判断四个物理量正负 | 矢量符号 |
| D3 | 读一次函数斜率、截距和面积 | 数学工具 |
| D4 | 解释`v-t`图一点、一段斜率和一块面积 | 图像前置 |
| D5 | 两道简单代数变形和单位换算 | 计算前置 |

路由：概念/图像任一低于60%先补前置；80%以上可跳过对应复习卡，但不能跳过章节出关。

#### S1 章节地图（5分钟）

核心链：

`加速度恒定 → 速度随时间线性变化 → 位移是速度的累积 → 图像斜率/面积 → 单阶段模型 → 多阶段与追及 → 动力学连接`

完成任务：学生不用原文，按顺序补齐六个节点并说出每条箭头的含义。

#### S2 概念建立（25—35分钟）

1. 匀变速与匀速的区别；
2. “加速/减速”由速度与加速度方向关系判断；
3. 初态、末态、时间间隔与位移；
4. 匀加速、匀减速不是简单等同于`a>0/a<0`；
5. 自由落体作为匀加速模型的条件与近似。

每小节配置：一个现象、一个正例、一个反例、两道即时题。即时题低于90%回到对应概念卡。

#### S3 规律与边界（35—45分钟）

核心关系按“最少公式 + 可推导”组织：

1. 速度—时间关系；
2. 位移—时间关系；
3. 速度—位移关系；
4. 平均速度关系及适用条件；
5. 中间时刻/中间位置关系（分清条件）；
6. 初速度为零时的比例关系，作为推论而非孤立口诀。

每个关系都要填写：研究对象、运动阶段、成立条件、正方向、单位、图像解释、最常见误用。

#### S4 单模型训练（40—60分钟）

| 模型 | 识别条件 | 首选表征 | 必须检查 |
|---|---|---|---|
| M1 已知三量求一量 | 单阶段、加速度恒定 | 代数 | 符号与单位 |
| M2 刹车停止 | 先减速后停止 | 分段时间线 | 是否错误倒车 |
| M3 自由落体 | 初速度与阻力条件 | 运动图+代数 | `g`方向与近似 |
| M4 图像求运动量 | 给出`v-t`或`x-t` | 图像 | 斜率、面积正负 |
| M5 逐段运动 | 条件在时刻发生变化 | 分段表 | 段间状态连续 |

每个模型顺序：示范1题 → 半填空模仿1题 → 独立2题 → 一道错解诊断。

#### S5 标准变式（30—45分钟）

变式轴：

- 改正方向；
- 改初速度；
- 改为反向运动；
- 改文字为图像；
- 改求解量；
- 增加无关信息；
- 改为两阶段；
- 要求判断解是否具有物理意义。

要求混合出题，避免学生靠连续同型题猜方法。

#### S6 实验与探究（35—50分钟）

任务链：

1. 说明实验目标和可观测量；
2. 选择器材并解释理由；
3. 纸带/数字化数据读取；
4. 求瞬时速度；
5. 用`v-t`图或逐差法求加速度；
6. 区分随机误差、系统影响与错误操作；
7. 改进实验方案；
8. 完成一段符合评分点的数据结论。

实验结果分项评分，不能只看最终加速度数值。

#### S7 易错修复（20—30分钟）

本章优先错因：

1. 用速度正负判断加速/减速；
2. 刹停后仍代公式导致“倒车”；
3. 平均速度公式越界；
4. 位移与路程混淆；
5. 图像面积忽略正负；
6. `x-t`曲线当运动轨迹；
7. 多阶段共用一个加速度或时间；
8. 逐差法下标/时间间隔错误；
9. 只写数字不写原始公式、方向和单位。

每类错误配“错解判断 → 解释错因 → 修复题 → 3天后变式重做”。

#### S8 满分能力（基础达标后，45—90分钟）

1. 多过程图像重构；
2. 追及相遇的距离函数、图像与临界条件；
3. 同题代数法/图像法比较；
4. 信息给予型变加速情境，但只要求使用题目给出的规律；
5. 实验方案评价与证据表达；
6. 规范书写：原始公式、条件说明、方向、结果检查；
7. 一道北京风格真题或已核验模拟题。

导数、定积分的显式运算不放在本层；它们属于C轨选学。

#### S9 章节出关（45—60分钟）

| 部分 | 建议占比 | 检测内容 |
|---|---:|---|
| 概念与条件 | 20% | 正方向、加减速、公式边界 |
| 代数模型 | 25% | 单阶段、刹车、自由落体 |
| 图像 | 20% | 斜率、面积、分段与转换 |
| 实验 | 20% | 数据、图像、逐差、误差 |
| 综合表达 | 15% | 多过程与评分点 |

采用第4.4节出关规则；未通过只回补对应节点。

#### S10 间隔复习

- 1天：5道概念/条件快测；
- 3天：两道核心错因变式；
- 7天：一组代数、图像、实验混合题；
- 14天：与牛顿定律或平抛前置连接；
- 30天：章节小卷或真题重组。

#### S11 融合迁移

章内：自由落体、追及相遇、多阶段、图像与实验。
跨章：匀变速 + 受力分析 + 牛顿第二定律；匀变速 + 功能关系；匀变速 + 电磁场中的带电粒子直线运动。
进入整卷前先完成“模型识别混合练习”，防止只会在同类题组中套公式。

### 5.4 样板章前三轮正常学习安排

当前先把“匀变速直线运动”做成前三轮可运行样板；R4—R6只保留已有学习证据的继承规则，不在本阶段制作完整高考复习内容。

#### R1 第一轮学习/预习（建议2—3次，共90—120分钟）

1. S0前置诊断：速度、加速度、正方向和一次函数图像；
2. S1章节地图：建立“加速度恒定—速度变化—位移累积—图像”链条；
3. S2概念：匀速/匀变速、匀加速/匀减速、自由落体条件；
4. S3只学习三个基本关系的物理意义，不集中背全部二级结论；
5. S4完成单阶段基础题，记录不会点形成“课堂关注清单”。

**R1出口：**概念检测≥80%，能够说明加速度恒定和正方向；基础题允许尚未完全达标。
**可上传证据：**预习作业、课堂前测、本人疑问照片。

#### R2 第二轮学习/同步巩固（随校内教学，建议1—2周）

1. 对照学校课堂修正R1疑问，补齐公式条件和二级结论；
2. S4五类单模型达到基础线，S5完成符号、图像、设问和分段变式；
3. S6完成纸带/数字化实验、`v-t`图和逐差法；
4. 每次上传作业、小测或错题目录，自动生成考试事件和S7修复任务；
5. 执行1/3/7天复测，避免学校讲完即结束。

**R2出口：**概念与条件≥90%、L1≥85%、核心实验≥80%，所有近期小测错题都有改进计划。
**可上传证据：**课堂作业、单元小测、实验报告、教师批注。

#### R3 第三轮学习/期中期末前（建议考试前7—10天）

1. 先做混合诊断，只回补遗忘节点；
2. 完成S7反复错因修复、S9章节出关和S11章内/已学章节融合；
3. 用一套限时阶段卷训练图像、实验、多阶段和表达；
4. 上传期中/期末正式试卷，比较考前判断与真实考试表现；
5. 为本次考试生成错题改进计划，完成网站复测并等待下一次线下考试验证。

**R3出口：**达到章节出关线，7天复测≥80%，正式考试暴露的关键错误进入改进闭环。
**可上传证据：**考前模拟卷、期中/期末卷、错题目录、教师评分标准。

## 6. 后续实施顺序与验收标准

### P0：权威边界核验

**工作：**核对课标、教材、北京考试文件，给26个章节和现有题目加依据。
**验收：**A轨所有节点有来源、版本、核验人和日期；无“凭模型判断必考”。

### P1：内容资产化

**工作：**先将“恒定电流与电学实验”资料拆为知识卡、模型卡、题目、提示、解析、错因和实验任务；匀变速资料暂不进入首期制作队列。
**验收：**每项有唯一ID；HTML/PDF不再是内容的唯一来源；重复项有唯一主版本。

### P2：样板章人工试运行

**工作：**让孩子在首个电学样板模块中按R1—R3实际走完正常学习周期；在每轮中按需执行S0—S11，上传作业、小测和正式试卷，记录时间、困惑、提示、错因、改进计划和复测。
**验收：**系统能回答“处于哪一轮、不会什么、为什么不会、下一步做什么、哪次线下考试验证”；孩子不需要家长解释文件顺序；至少一个考试改进计划完成网站复测并在后续线下考试得到验证。

### P3：题库补齐

**工作：**先北京真题与区级高质量模拟，再选全国和外省适配题。
**验收：**每道题有可核验来源、版权/使用状态、章节、模型、能力、难度、用时、评分点和错因；外省题不冒充北京仿真题。

### P4：扩展章节

**首期电学顺序：**恒定电流与电学实验 → 磁场与安培力 → 洛伦兹力与带电粒子 → 静电场查漏补缺 → 电磁感应 → 交变电流与电磁波；具体顺序允许根据学校教学进度调整，但前置依赖不能跳过。
**验收：**只有样板章经过孩子试用并调整后，才复制结构；禁止一次性批量生成全部章节。

### P5：网站开发前置条件

开始写网站代码前，至少应冻结：课程树v1、六轮周期规则v1、任务状态机v1、掌握度与线下重评规则v1、题目/考试事件/错题改进计划数据规范v1、电学首个样板模块前三轮内容v1和涉及未成年人试卷的隐私/授权/备份/删除策略v1。否则开发会把现有静态文件问题固化。
