# 电学三轨对齐审计与修正计划

## 1. 结论

当前首版与原规划**部分一致，但在上传试卷后发生了明显偏移**。

一致之处是：保留了 E1—E8 模块树，完成了恒定电流 R1—R3、真实错题修复和部分模块检测。偏移之处是：页面主要按“学习轮次”和“考卷题号”组织，A/B/C 三轨没有成为每个知识点的主结构；部分模块只有简短模型卡，却在总入口中被写成“完整首版”；现有小测也没有分别形成基础卷、拓展卷和强基卷。

因此，现阶段不能宣称“电学模块全部完成”。准确状态应是：**A轨功能样板已形成，B/C轨尚未系统建设，若干E模块只有范围占位页。**

## 2. 必须恢复的两个正交维度

### 2.1 内容层级：A/B/C轨

| 轨道 | 定位 | 学习与考核结果 |
|---|---|---|
| A 基础核心 | 教材与北京普通高考主线；概念、规律、实验和标准模型 | 通过基础卷后可进入B，也可继续间隔复习 |
| B 拓展迁移 | 课标内复杂情境、多过程、开放探究和跨模块迁移 | 可由A通过后进入，也允许诊断后直接进入；通过拓展卷后完成B轨 |
| C 强基拓展 | 强基、竞赛衔接或大学先修；不得混入普通高考主线 | 需显示前置要求；通过强基卷后完成C轨 |

### 2.2 学习周期：R1—R6

R1—R6表示学习发生在什么时间，A/B/C表示学习什么深度。二者不能互相替代。例如“E2-B-R2”表示恒定电流拓展轨的第二轮同步学习，而不是把R2误当成拓展层。

## 4. 考卷上传造成的偏移

真实考卷本应是“学习证据”，用于调整某个知识节点的掌握度和生成修复任务；它不应决定课程树本身。此前建设把第3、8、10、12、16、18、19题快速转成独立页面，有助于验证错题闭环，但也带来三个问题：

1. 页面顺序被单张考卷牵引，而不是按每个模块的A/B/C知识结构推进；
2. 错题修复页被误当成模块内容完成的证据；
3. 第18、19题等综合内容进入页面，并不等于相应B轨或C轨已经完整。

修正规则：考卷题目只挂接到 `模块—知识点—轨道—轮次`，不得反向替代知识点目录和分轨考卷。

## 5. 正确的学习路由

每个E模块统一采用以下路由：

```text
轨道选择/诊断
├─ A基础学习 → A基础卷 → 通过 → B拓展或结束当前目标
├─ B直接诊断 → 达标则直接学习B → B拓展卷 → 通过 → C强基或结束
└─ C前置诊断 → C强基学习 → C强基卷 → 通过
```

允许学习者直接进入B，但系统必须先提示前置要求并提供简短诊断。A卷不通过时只回到具体A知识点；B卷不通过时优先回到B知识点，若证据显示基础缺口才降回A；C同理。

## 6. 每个知识点的统一数据要求

每个知识点必须至少记录：

`模块ID、知识点ID、轨道、轮次、前置知识、学习目标、讲解、正例、反例、公式条件、实验/图像（适用时）、即时检测、考卷ID、通过线、回补节点、来源、核验状态`。

同一个物理概念在三轨中不是简单复制：A强调定义、条件和标准模型；B强调条件变化、迁移和综合；C强调更深推导、模型推广和强基表达。

## 7. 修正顺序

1. 先修正总入口和状态用语，不再把E1—E8称为“完整首版”；
2. 用E2/E3建立第一个真正的A/B/C三轨样板；
3. 将现有R1—R3和考卷错题重新标注到E2/E3的具体轨道与知识点；
4. 分别建设A基础卷、B拓展卷、C强基卷；
5. 验证“通过A进入B”和“诊断后直接进入B”两条路由；
6. 样板稳定后再按E1、E4、E5、E6、E7、E8逐模块复制，不再按单张考卷扩张页面。
