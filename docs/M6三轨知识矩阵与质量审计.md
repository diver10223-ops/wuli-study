# M6 万有引力与宇宙航行三轨知识矩阵与质量审计

## 三轨内容

- A轨（基础核心）：开普勒定律、万有引力定律、重力与万有引力、天体质量密度、圆轨道卫星、宇宙速度与同步卫星；正式卷门槛80%。

- B轨（迁移拔高）：双星模型、多星简化、变轨定性、椭圆轨道定性、临界发射、航天信息题；正式卷门槛75%。

- C轨（强基先修）：引力势能、椭圆轨道定量、双体问题、有效势初步、轨道参数、数值轨道模拟；正式卷门槛70%。

## 统一流程

每轨均包含诊断、学习、模型、即时检测、正式卷和间隔复测；正式卷和复测都通过才表示稳定。B/C不能补偿A轨。
